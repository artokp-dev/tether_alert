# 앱 꺼도 오는 텔레그램 알림 (구글 앱스크립트)

웹앱은 "볼 때"용이고, 이건 **"안 볼 때(앱 꺼짐)"용**입니다.
구글 서버가 1분마다 시세를 확인해서, 조건에 맞으면 텔레그램으로 푸시 알림을 보냅니다.

## 알림 조건
- **거래소 차이**: 업비트·빗썸 USDT 가격차가 `SPREAD_THRESHOLD`원(기본 3) 이상
- **김치 프리미엄**: 평균 김프가 `PREMIUM_HIGH`%(기본 0) 위 또는 `PREMIUM_LOW`%(기본 -1.5) 아래

값은 `Code.gs` 맨 위에서 바꾸면 됩니다.

## 설치 순서 (5분)
1. https://script.google.com 접속 → **새 프로젝트**
2. 기본 `Code.gs` 내용을 지우고, 이 폴더의 **`Code.gs` 전체를 붙여넣기**
3. 맨 위 `BOT_TOKEN`, `CHAT_ID`를 **내 값으로** 수정
   - 봇 토큰: 텔레그램 [@BotFather](https://t.me/BotFather)에서 발급받은 값
   - chat id: 내 텔레그램 chat id (모르면 [@userinfobot](https://t.me/userinfobot)에게 말 걸면 알려줌)
4. 위쪽 함수 선택 드롭다운에서 **`setup`** 선택 → **실행(▶)**
   - 처음엔 구글 권한 승인 창이 뜸 → 허용
   - 성공하면 텔레그램에 "✅ 알림 봇 시작" 메시지가 옴
5. 끝! 이제 앱을 꺼도 조건 충족 시 알림이 옵니다.

## 참고
- **도배 방지**: 조건에 "진입"할 때 1번만 보냄. 조건을 벗어났다가 다시 들어오면 다시 보냄.
- **1분 간격**: 구글 앱스크립트 최소 간격이 1분. 몇 초짜리 순간 스프레드는 놓칠 수 있지만, 김프처럼 지속되는 조건은 잘 잡습니다.
- 기존에 쓰던 "차익 알림" 앱스크립트가 따로 있으면, 중복 알림을 피하려고 **그 트리거는 꺼두세요** (이 스크립트가 차익+김프 둘 다 함).
- 잘 오는지 확인: 함수 드롭다운에서 `testNow` 실행 → 텔레그램 확인.
